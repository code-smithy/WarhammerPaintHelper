# Warhammer Paint Helper

Warhammer Paint Helper is a single-page color scheme generator for miniature painting.
It is aimed at Warhammer and Age of Sigmar hobbyists, but it can also be used for any
miniature, model, or tabletop painting project that needs a quick palette idea.

## What It Does

The app lets you pick a main color from a color wheel or enter a HEX value directly,
then generates painting-friendly palettes around it. It includes several color scheme
types such as complementary, split-complementary, triadic, tetradic, analogous,
monochrome, zenithal, warm/cool contrast, and grimdark-style palettes.

It also provides:

- A miniature preview showing how the generated colors might read on a model.
- Age of Sigmar role planning for armor, robes, leather, wood, metals, magic effects,
  weapons, bases, and accent areas.
- Base environment suggestions, including ruins, graveyards, forests, swamps, deserts,
  snow, volcanic ground, arcane crystals, coastal bases, and Ghurish badlands.
- Shade, layer, highlight, and focus-light color steps for each main palette color.
- Optional accessory material colors for wood, leather, cloth, bone, white, iron,
  silver, bronze, and gold.
- A copy button for exporting the generated palette and painting notes.

## How To Use

Open `WarhammerPaintHelper.html` in a browser. No build step, package install, or local
server is required.

Pick a color, choose a scheme, adjust saturation/lightness, select a finish style, and
use the generated guidance as a starting point for your miniature paint plan.
