# Security Policy

## Supported Versions

Security updates are provided for the latest released minor version of Warhammer
Paint Helper and for the current default branch while it is under active
development.

| Version | Supported          |
| ------- | ------------------ |
| 0.10.x  | :white_check_mark: |
| < 0.10  | :x:                |

Older versions may continue to run as static files, but they do not receive
security fixes once a newer minor version has been released.

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately through GitHub's
security advisory flow for this repository. Do not open a public issue with
exploit details, proof-of-concept code, private data, or other sensitive
information.

When reporting a vulnerability, include as much of the following as you can:

- A clear description of the issue and affected feature.
- Steps to reproduce the behavior.
- The affected version, browser, and operating system.
- Any proof-of-concept details needed to confirm the issue.
- The impact you believe the issue could have.

You can expect an initial acknowledgement within 7 days. After the report is
reviewed, it will be either accepted for remediation or declined with an
explanation when possible.

If the report is accepted, maintainers will coordinate a fix, prepare a patched
release or update to the hosted static app, and publish disclosure details after
users have had a reasonable opportunity to update. Please avoid public
disclosure until the fix is available.
